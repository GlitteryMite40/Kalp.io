## Known limits

- **In-Memory Model Cache:** The model selection cache resides on `globalThis` and is scoped per serverless function instance. It resets on cold starts, can temporarily differ across concurrent serverless instances, and the 60-second status page refresh cooldown is enforced per instance.
- **Request Guards:** User input length caps, payload limits, and rate limits will be introduced in step `04.6`.
- **Prompt Version Tracking:** Stage prompt versions are accessible programmatically via `stageMeta(stage, model)` and will be persisted alongside stage generation outputs once database persistence is integrated.
